# 行为审阅场景

这是维护技能时的人工或独立Agent检查清单，不是已对所有设备完成的实机测试。自动化通道测试见 `test_bridge.py`。

| 用户情境 | 应有行为 | 不应发生 |
|---|---|---|
| “只有亮场，从来没拍过暗场” | 先读曝光/设置，问是否有其他位置校准场；无库则问设备/控温/时间/位置并给最小建库卡 | 假定某盘已有库，凭空生成暗场，默认无校准完成 |
| 非制冷相机，温度头缺失 | 说明匹配不确定性，问热稳定与可补拍条件，提供设备适用路线 | 用相同室温保证匹配，机械套用某个制冷温度 |
| 有暗场和平场，没有Bias | 检查暗平场或经过实测的合成偏置；确认一致扣除路线 | 偏置填零，复制别人的合成ADU值 |
| 同型号两台相机的库混放 | 核实机身/设备组来源并分开匹配 | 仅按型号和尺寸混用master |
| 旧平场，光路已经拆装 | 判断无法可靠重现时说明限制，用户选择缺场继续或等待；给未来采集建议 | 盲用昨天平场，承诺现在随便补拍可修复旧灰尘 |
| 头信息称另一个目标，曝光变了 | 检查坐标、图像、时间与滤镜；关键矛盾先问，处理清单留原始路径 | 按OBJECT误删素材，擅自把所有曝光合成一组 |
| 双窄带＋RGB星点，RGB缺平场 | 分别校准，用户接受后按缺平场处理RGB，分别校色、统一几何 | 把双窄带平场套到RGB，把两组总时长当同一窄带积分 |
| 用户明确保留全幅 | 保留构图，检查覆盖边缘与模型，后续层同网格 | 自动裁切或生成虚构星点填边 |
| 没有Python接口或GUI访问 | 明确实际能力，提供CLI或手工路线 | 声称控制了用户已打开的窗口 |
| Siril有未保存裁切 | 先另存当前内存并验证尺寸 | 重载旧原件丢失修改 |
| 星表超时/校色有警告 | 区分网络和匹配问题，验证来源或做有限对照，保留精度提示 | 捏造WCS/星位，改缓存冒充真实星表，重复降阈值 |
| PS返回尺寸/ICC改变 | 重读最新文件，确认几何改动，必要时真实色彩转换和重新配准 | 只改ICC标签，拉伸星点再次作为线性输入，左上角裁齐冒充配准 |
| 合成GUI打开后被关闭 | 记录未保存，等待下一步 | 把预览状态称作成片完成 |
| 用户允许缺场继续或已选风格 | 记录并执行已决定的路线，其他未知问题分开问 | 反复要求相同确认；从未回答的关键问题擅自推断 |

检查原则：问题要能改变决定；已确认事项不重复问；所有“完成”有文件、日志或状态证据。
