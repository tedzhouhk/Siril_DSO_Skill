# Siril 深空图像处理

## 1. 先确认任务，再读素材

第一次开始时先确定工作目录和目标：“这次素材在哪里？拍的是什么目标？”已经给过的内容不重复问；用户让看文件夹名时，先检查目录和实际图像。

按 [信息确认与提问](references/intake.md) 工作：先读文件、FITS头/RAW元数据、日志与代表帧，再问无法核实或相互矛盾的关键项。多问有决策价值的问题，不用固定设备、文件夹名或上次任务代替答案。每轮通常1–3个相关问题；解释它影响哪一步，等待期间继续独立工作。用户不确定时保留“未知”，不要逼其猜参数。

确认本轮要做清点、叠加、后期、建库还是现有Siril窗口中的逐步操作。发现已叠加、已校准或已拉伸数据时从相应阶段接续，避免重复校准。询问影响当前流程的软件版本、操作系统、彩色/单色相机、滤镜或光路；能从文件核实的先核实。

清单至少包括：相机/设备组、曝光、Gain/ISO、Offset、读出模式、binning/ROI、尺寸、传感器温度与设定温度、CFA、滤镜、日期及线性状态。区分FITS与同名JPG缩略图，按相机、设置、曝光、滤镜和夜晚分组。缺字段不等于值为零；相同型号不保证来自同一相机。

## 2. 约定目录和交付

说明本次输入组、中间文件位置、最终结果位置和校准路线；明确的用户约定直接沿用。没有其他约定时采用：

```text
拍摄目录/目标/
  滤镜或素材组/
    原始素材
    process/                 # 转换、主场、校准、配准、日志、拒绝图
      inspection/            # 清单、质量指标和诊断图
      postprocess/           # 后期检查点、PS交接、GUI状态
  目标_滤镜_线性叠加.fit
  目标_合成_v01.fit
  目标_合成_v01.tif
  目标_处理总结.html
```

原始素材直接位于目标目录时，在该目录建 `process`。层级不清楚时问哪个目录代表目标，不能机械取父目录。不同滤镜、相机与曝光组隔离中间文件。

默认最终32位FITS、16位RGB TIFF和报告只放对应目标目录，不向整晚拍摄总目录另造副本。同内容改名不算新处理版本。保留原始素材、线性叠加与已接受检查点，后期用新版本；覆盖、清理或改变已约定位置前核实用户意图。

## 3. 找校准场；没有库时帮助建库

先检查用户给定工作目录。缺所需场时询问有无暗场/偏置/平场/暗平场库及其位置；已给出的库不重复问。只检索已知或用户提供的位置，访问失败不等于没有库。

使用 [校准组合与匹配](references/calibration.md) 选择路线。检查master的来源、制作方法、是否去偏置、归一化和适用参数。不要因文件最新、尺寸相同或传感器型号相同就选用。日期不是统一过期标准；用条件匹配与代表帧试校准验证。

**没有库、库不匹配或用户想长期复用时，读 [建立与维护校准库](references/calibration-library.md)。** 先问可用相机、是否可控温、能否补拍及库的保存位置，依据本次亮场生成最小建库计划、具体拍摄参数、张数起点和耗时估算。帮助完成目录、清单、master制作与试校准；不要只说“请补暗场”，也不默认用户已有任何库。

缺平场尤其要问光路、滤镜、方向和灰尘状态是否还能重现。无法补拍时说明可行的缺场路线及残留问题，让用户选择继续、等待或只做诊断；用户已明确接受的路线无需重复确认。关键匹配信息未知时不自动套用master。

## 4. 执行校准、配准和叠加

读 [手动流程与排错](references/manual-workflow.md)，依据当前版本帮助确认命令。关键约束：

- 含偏置主暗场路线为 `L − D_raw`，亮场不再减偏置；已去偏置暗场需另行正确移除亮场偏置。平场用偏置或匹配暗平场的一致路线，避免重复扣除。
- CFA先校准，再按目的解拜耳。单色不解拜耳；CFA Drizzle或直接Ha/OIII提取需保持CFA并走其专用流程。
- 先小批试校准，查看反向暗角、灰尘环、辉光、坏点和异常电平，再处理全组。保留合理浮点负值，不为“好看”剪黑。
- 依据真实星形、FWHM、圆度、星数、背景与构图选参考帧和筛片；不固定丢片比例。配准失败先查图像，不盲目降低检测阈值。
- 两遍配准完成不代表已重采样；核实变换已应用、包含标记生效、实际输出帧数与曝光和正确。
- 校准主场默认不做输出归一化；最终亮场的归一化、剔除和权重依据帧数及质量选择。交付线性32位浮点FITS，检查拒绝图和结果重新打开是否正常。

双窄带星云＋独立RGB星点、单色多滤镜、多晚或混合曝光按 [多组素材与窄带](references/multigroup.md) 处理；两种用途的曝光分开记录，不将其混成一个亮场序列。

## 5. 每次叠加后交付总结

按 [处理报告](references/reporting.md) 自动交付可保存的总结，再按已约定阶段继续后期。报告应回答：用了什么场，各自输入/使用多少张、多少秒，库何时拍摄，master何时制作，每一步的参数、结果、路径和预览。未知字段如实标注；后期继续时更新同一报告。

## 6. 后期与用户审美选择

读 [后期、分层与交付](references/postprocessing.md)。根据数据选择：保存当前检查点 → 裁切或保留全幅 → 去梯度 → 验证坐标与适用校色 → 适度降噪 → 星点分离 → 分层拉伸/编辑 → 合成。不是每张图都需要所有步骤；保留全幅、无需PS或不去星的选择都有效。

询问会改变画面内容或风格的事项：裁切、窄带映射、拉伸力度、星点强弱、是否进外部编辑器；可先做同尺度候选。没有SII时不把金蓝两通道映射称作真实SHO。没有PS或某款插件时使用可用替代路线，不把收费软件、GPU或模型下载当作默认前提。

去梯度不能代替缺失平场，FWHM改善不能证明亮星没有新增光晕，两层相加正确不能证明去星没有误分星云。真正拉伸后用Linear显示并核对ICC。PS返回必须重读最新文件并验证尺寸、方向、色彩配置和对齐；交互合成只在用户保存后称为成片完成。

## 7. 用户希望在现有Siril窗口看过程

读 [GUI连接与桥接](references/gui-control.md)。先核实本机能力和连接；独立CLI不冒充控制现有窗口。没有Python接口或无法访问桌面时，改为已说明的CLI或逐步手工操作。

按用户已授权的阶段执行，不要求逐条命令重复审批。用户已有未保存裁切或编辑时先另存当前内存检查点，不重载旧图覆盖其工作。连接超时先查状态，长任务不自动重发，错误后保留日志并从可验证检查点恢复。

参数、软件路径和模型选择均以当前机器与素材为准。官方入口集中在相关参考文件中；本技能不会把某次实拍的数值当作通用默认。
