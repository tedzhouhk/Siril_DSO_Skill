# 校准组合与补拍决策

以下是常规深空线性原始素材的决策摘要。依据为 [Siril 手动教程](https://siril.org/tutorials/tuto-manual/)、[校准说明](https://siril.readthedocs.io/en/stable/preprocessing/calibration.html) 和 [合成偏置教程](https://siril.org/tutorials/synthetic-biases/)。具体执行前核对相机特性和 Siril 版本。

## 校准场有无的八种组合

默认都有亮场；D 表示匹配且未先减偏置的主暗场，F 表示原始平场序列，B 表示匹配偏置。以下“减场”都使用经适当叠加的 master，而非随意取一张。这里的平场需要校准、叠加及归一化，不是用单张原始平场直接相除。

| D | F | B | 路线 |
|---|---|---|---|
| 有 | 有 | 有 | B 校准 F 后制作主平场；亮场减 D，再用主平场校正，不重复减 B。 |
| 有 | 有 | 无 | 找匹配暗平场或经验证的合成偏置来校准 F；亮场减 D 后使用主平场。两者都无时，先尝试补拍，不能默认偏置为零。 |
| 有 | 无 | 有 | 亮场减 D，不再减 B；缺平场的暗角、灰尘和像素响应问题仍存在。 |
| 有 | 无 | 无 | 亮场减 D，随后配准和叠加。 |
| 无 | 有 | 有 | B 校准 F；亮场减 B，再用主平场校正。暗电流/辉光残留可能影响平场效果。 |
| 无 | 有 | 无 | 先找/补拍有效偏置或验证合成偏置；只有暗平场时，可校准 F，但它不自动替代亮场的偏置/暗场。说明亮场零点与暗电流缺口，不能声称完整校准。 |
| 无 | 无 | 有 | 亮场减 B，再配准叠加；其余缺陷仍可能存在。 |
| 无 | 无 | 无 | 用户选择继续时，转换、适当去马赛克、配准、筛片、叠加；标明未做校准及局限。 |

暗平场与偏置用于平场校准时，通常选择一种一致流程；含偏置的匹配暗平场已经移除了平场偏置，不再额外减 B。已去偏置的暗平场则需要核对制作记录，不能混用含义。

合成偏置只近似固定电平，不替代暗场中的空间结构。缺暗场时减偏置有帮助，但不等于消除暗电流。先用少量图像核实实际效果。

暗场优化不是默认解决不匹配库的方法：若确有必要，参考 [官方说明](https://siril.readthedocs.io/en/stable/preprocessing/calibration.html#dark) 分别处理暗场和亮场的偏置，尤其检查 CMOS 辉光的缩放残差。不要在没有查证相机行为时直接开启。

## 补拍卡片的内容

以下张数仅为实务起点，按已有素材、时间预算和相机行为调整，不声称是官方统一要求。用用户实际参数替换；无法确定的字段保留“待确认”。

### 暗场

- 建议起点 20–40 张；与对应亮场匹配曝光、温度、GAIN/ISO、OFFSET、读出模式和几何。
- 完全遮光，留意机身/接口漏光；制冷机先稳定温度，非制冷机尽量重现实际传感器温度，不能以相同室温保证等效。
- 用时约为张数 ×（曝光＋读出间隔），另加温度稳定时间；从素材读出不同曝光组时，分组给时间。
- 检查是否漏光、温漂、异常条纹与辉光；不能满足匹配条件时解释残差风险。

### 平场

- 建议每个滤镜/光路状态 20–40 张；保持与亮场相同光路、相机方向、光圈、灰尘状态和足够接近的焦点，采用匹配的电子设置。
- 用均匀、稳定的光源；曝光由实测直方图决定，保持在线性区、避开黑端截断与任一通道饱和。可把约满量程的 1/3–1/2 当初始试拍位置，再核对相机建议、原始统计和 CFA 各通道，不当成所有相机的固定目标。
- 留意光源闪烁与相机短曝光特性，不编造通用固定秒数；选定曝光后判断是否需要匹配暗平场。
- 光路已拆装、旋转、清洁或灰尘改变时，新平场可能不能修复旧数据。明确说明无法可靠补拍的原因，不要求用户无效重拍。

### 偏置

- 建议 50–100 张；遮光，匹配 GAIN/ISO、OFFSET、读出模式和几何，使用相机支持且适用的最短曝光。
- 某些相机最短曝光下行为不适合校准平场，应核对型号并考虑匹配暗平场，不强推最短曝光。
- 若设备已有可靠黑电平标定，可评估合成偏置；ADU、FITS 存储缩放和采集软件 OFFSET 数值不是同一概念。不能照抄别人的数值。

### 暗平场（flat-dark / dark-flat）

- 建议每种平场曝光/设置 20–40 张；完全遮光，匹配对应平场的曝光、温度、GAIN/ISO、OFFSET、读出模式和几何。
- 先确定平场曝光再补拍暗平场；不同滤镜若平场曝光不同，按曝光及设置配套。
- 它校正平场中的偏置和暗信号，不用亮场的长曝光暗场直接替代。

## 给用户的输出示例结构

“这组亮场是【相机】【滤镜】【曝光】【GAIN/ISO】【OFFSET】【温度】【几何】，缺【类型】。库中【路径】因【具体不匹配/失效证据】暂不能用。若能重现【必要条件】，建议补拍【张数】张、每张【已知曝光/需试拍确定】，约【估算时间或未知原因】，保存到【建议目录】。拍完检查【项目】。若条件已改变，改走【可行降级路线】，预计残留【缺陷】。”

不要把所有可能字段变成用户必填问卷；只追问影响当前选择且无法从已有文件确定的值。

没有校准库或想建立可复用master时，继续阅读 [从零建立与维护校准库](calibration-library.md)。已有库只在参数和验证结果支持时复用，不因文件名或日期单独选中。
