# 手动操作与排查

依据Siril官方手动流程与实际操作经验整理。命令、按钮与默认值会随版本变化，运行前以本机帮助核实；这里的数值是判断起点，不是固定预设。

## 目录、转换与序列

- 沿用用户指定规则：每个素材组目录内的 `process` 集中存放中间文件，最终线性叠加 FITS 放该组所属的目标目录；具体层级和示例见 [SKILL.md的目录约定](../SKILL.md)。每次切换数据集后确认工作目录及当前序列，并显式设置最终输出路径，避免默认写回 `process`。
- 转换前核对列表，每处理完一组清空列表再添加下一类，避免 Light/Dark/Flat/Bias 混入同一序列。转换后核对每组帧数、几何和 CFA 信息，不只是检查文件是否生成。
- 原始目录混有 FITS 和 JPG 预览时，Siril 的 `link basename -out=...` 只处理 FITS，避免 `convert` 把预览也算进去。Windows 未启用符号链接时可能实际复制，这是正常回退；确认日志中的输入数、成功数和输出路径，不为节省空间擅自修改系统开发者模式。
- 常规命名示例：light → pp_light → r_pp_light；flat → pp_flat → master_flat.fit。前缀仅作线索，仍需从日志与实际状态确认。master_bias.fit、master_dark.fit 也应保留设置/日期或制作记录以便区分。
- 搜索不到序列：先核对工作目录、文件名及扩展名设置，重新搜索。保留 .seq 的参考帧、排除标记、质量及配准记录，不手工修改索引“修复”流程。.lst 可用于复用星点检测结果，参数改变后按软件规则重算。
- 预估转换、校准、配准的多份输出及 32-bit RGB 体积。可评估 FITSEQ 与资源限制；不要以排错为由自动删除中间序列或原始数据。

## 常规主场与亮场叠加起点

以下为常见实务起点，经 [官方叠加说明](https://siril.readthedocs.io/en/stable/preprocessing/stacking.html) 核对归一化含义。并非所有数据都使用同一剔除方法。

| 输入 | 输入归一化 | 常规输出 |
|---|---|---|
| Bias / Dark / 匹配 Dark-flat | 无 | 保留校准电平的 master，关闭输出归一化 |
| 已正确校准的 Flat | 乘法 | master_flat，关闭输出归一化 |
| 已配准 Light | 加法＋缩放（Additive + Scaling）作为常规起点 | 32-bit 浮点线性 FITS |

- 帧数足够时可用平均值＋像素剔除，Winsorized Sigma 3/3 可作为候选起点，需看拒绝图、星点和残留调整。帧数很少（约 6 张及以下）可评估 Percentile Clipping；大序列可根据实际异常与版本评估其他算法。
- 输入归一化用于匹配各帧背景/离散程度，输出归一化则调整最终数值范围，两者不同。主校准场必须保留电平，不能启用输出归一化。最终亮场常规可关闭它，但不要说“开启即非线性拉伸”；显示 AutoStretch、像素拉伸与数值归一化也不能混为一谈。
- master 不先去马赛克，不做最终 RGB 通道均衡。常规亮场最终 RGB 均衡可暂关，保留后续颜色校准空间；按任务决定，不作为普适禁令。
- 校准平场可按需要用 Equalize CFA；它不是解拜耳，也不替代后续颜色校准。

## 明确偏置扣除的代数关系

令 B 为偏置，D_raw 为含偏置的匹配暗场，D_cal = D_raw − B。平场校正前，以下两种亮场计算一致：

- L − D_raw：匹配原始暗场路线，不再另减 B。
- (L − B) − D_cal：明确分离偏置的路线，暗场已去偏置时亮场仍要正确移除自己的偏置。

真正的问题是 (L − B) − D_raw 等重复扣偏置，或只算 L − D_cal 而遗漏亮场偏置。不能把“已去偏置暗场＋亮场减偏置”本身误称为双重扣除。

不能根据“统一处理”或文件名等模糊描述直接把所有校准框全勾上。先核对 master 制作日志及本机版本处理语义；暗场优化按 [官方校准说明](https://siril.readthedocs.io/en/stable/preprocessing/calibration.html) 单独处理。匹配含偏置暗平场校准平场时，也不要再重复减偏置。

## 坏点修正与解拜耳

- 使用 Cosmetic Correction 前先 Estimate，检查预计修正数量和图像。约超过 1% 出现红色提示时，调整阈值或关闭相应修正；不是为了把数字压低而忽略真实坏点。CFA 数据正确启用对应选项，核对 Bayer Pattern。
- 常规 OSC：转换与校准场阶段不去马赛克，在 Light 校准输出时去马赛克；单色不去马赛克。CFA Drizzle 则保留校准后的 CFA 输入，遵循专门流程。
- 棋盘格/颜色错乱先检查原始与已去马赛克数据混用、Bayer Pattern、文件翻转及读取设置。正常显示偏绿不能单凭这一点判作 Bayer 错误。

## 参考帧、配准和筛片

- 参考帧兼作输入归一化基准。选星点清晰圆整、背景正常、无云/拖线且构图重叠合理的帧；避免只追求最小 FWHM。可以手选或按当前版本用两遍配准挑选。
- 深空且重叠充分时采用全局星体配准。常规 RGB 默认绿通道，单色用亮度；滤镜和信号状况可能需要不同选择。
- Homography 适合一般及广角场景；无明显畸变时可评估 Similarity。数学自由度最低星对数与全局算法实际匹配要求不同；三角匹配通常要求至少 3 对，Homography 至少 4 对，以当前版本文档为准，不把 Similarity 的数学 2 对当作全局配准必然可用。
- 配准失败先看参考帧、构图重叠、云、失焦、拖线和模型，再检查 Dynamic PSF。星太少时逐步降低检测阈值并观察真实星点；噪点/热像素误检时反向调整。半径 5、阈值 1.0 或示例星点数量都是示例，不是目标。不因显示拉伸变化直接推断检测算法的输入像素已改变。
- 两遍配准可能只记录变换而不输出重采样图。需要旋转/缩放等复杂变换时，确认已应用配准并输出可叠加序列，不能看到配准成功日志就直接当作已生成 r_ 图像。只有平移等支持路径需按版本区别处理。
- 综合 FWHM、wFWHM、圆度、背景、星数及实际图像剔除云、拖线、失焦、遮挡等异常帧。wFWHM 包含检测星数的信息；帧排除标记不会删文件。质量接近时避免为追求最好指标丢掉大量有效曝光。
- 最终选“仅包含帧/Selected”等对应条件，核对排除状态实际生效及真正参与帧数。权重可从无开始，根据质量/噪声差异评估，不能把 wFWHM 自动等同于所有场景最佳权重。
- 对候选坏帧与清晰参考帧做同坐标局部对比。排除后读取 `.seq` 的包含标记确认编号正确，不手改索引；已验证的Siril 1.4.5中， `unselect seq 37 40` 排除编号 37–40，不应类推到所有 API 的零/一基索引。
- 两遍配准后的实际路径可为 `register pp_light -2pass` → 审查质量/选择 → `seqapplyreg pp_light -filter-included` → `stack r_pp_light ... -filter-included`。输出前缀以日志为准。拒绝图留在 process；若和结果同名输出到同一目录，可先在 process 叠加，验证后仅把最终 FITS 放到目标目录。

配准与 CFA Drizzle 例外依据：[官方配准文档](https://siril.readthedocs.io/en/stable/preprocessing/registration.html)。

## 结果检查与故障定位

| 症状 | 优先处理 |
|---|---|
| 灰尘圈加重、反向暗角、过修正 | 复核平场光路/灰尘变化、平场零点及 Bias/Dark 状态；别先用背景提取掩盖 |
| 大量配准失败 | 看参考帧、星点真伪、重叠与模型，必要时分组；不只一味降低阈值 |
| 卫星线/热像素残留 | 查看帧数、拒绝图和对齐；可适当减小 High Sigma，也考虑原帧异常，勿损伤真实星核 |
| 低值异常、正常像素误剔除 | 按低/高端拒绝图分别判断 Low/High Sigma；过度剔除时提高相关阈值，先排查归一化错误 |
| 黑边或覆盖不均 | 检查配准位移与输出取景；叠后裁公共区域或按任务选择取景，不把缺数据当真实暗信号 |
| 结果未保存 | 检查输出路径、磁盘、文件是否已存在及覆盖设置；内存中的完成图不等于文件已落盘 |

最终核对：主场可追溯、当前序列正确、配准已应用、坏帧选择生效、实际参与帧数和累计曝光正确、剔除图合理、输出确已保存到对应目标目录且可重新打开，是线性 32-bit FITS。完成后展示结果，与用户一起逐步决定裁剪、去梯度、校色和拉伸；后期另存，不覆盖线性叠加原件。

## 跨系统路径与访问

使用本次用户提供的实际路径，不默认盘符、网络共享、相机或温度。映射盘在某些进程/权限环境中可能不可见，先检查访问环境；不可见不等于库不存在。不要猜测网络共享地址或自动修改系统设置。
