# 叠加与处理总结

每次目标/滤镜组叠加后，默认交付一份可复查总结。它用于查参数、复现流程和复用校准场；不要求用户使用PS。用户只要求清点时，记录已有事实而不伪造已执行步骤。

## 时机与位置

- 处理期间逐步收集清单、FITS 头、主场来源/哈希、命令计划、实际日志和筛片状态；不要到最后仅凭记忆还原。
- 每个目标/滤镜组完成线性叠加后即生成第一版报告。聊天给简要结论和可用入口；目标目录保存 `目标_处理总结.html`，默认图片内嵌、无需网络或临时路径即可阅读。用户指定 DOCX/PDF 等格式时按相应技能生成，不额外增加格式。
- 结构化记录放 `process/inspection/processing_summary_data.json` 或同等已有清单，诊断图按既定 process 规则保存。复用已存在的检查数据，不重新跑已完成的处理来凑报告。
- 后期继续时更新同一总结的阶段状态并保留采用/淘汰记录。可同时保存版本或更新日期；未经完成的步骤写“待处理”，不能提前写成已执行。

## 必填内容

### 结果概览

目标名称、素材目录、拍摄日期、处理日期、相机、滤镜、Gain/ISO、Offset、binning、温度、尺寸、Siril版本。滤镜若仅从目录获知，应注明。列最终线性 FITS 路径、32位状态、参与张数与总曝光；提供显示预览时标明“仅显示拉伸，FITS仍为线性”。

### 素材与校准库表

每行对应实际参与的一组 Light / Dark / Flat / Bias / Dark-flat：

| 字段 | 要求 |
|---|---|
| 原始来源 | 实际目录、相机组、必要的代表文件；不要只写“用了暗场” |
| 数量 | 库中/输入数量、用于该Master的原始张数、本次亮场保留数分别列明；JPG缩略图不计曝光 |
| 曝光 | 单张秒数，混合曝光按组拆开；毫秒可同时写，例如0.001秒（1毫秒） |
| 累计 | 明确各组张数×单张时间，校准素材时间不计入目标的亮场总曝光 |
| 日期 | 原始素材 DATE-OBS 起止范围；Master 生成日期另列；复制/修改时间只作文件属性 |
| 条件 | 相机、Gain/ISO、Offset、温度、binning/ROI、滤镜/光路等已知匹配项与关键未知项 |
| 状态 | 本次新建/复用Master、是否已减偏置或归一化、未使用/缺失的场及原因 |

时间显示采用用户确认的时区；保留原始时间与转换依据，注意夏令时。未知时区先询问或保留带明确说明的原值，不能硬编码某个时区。DATE-OBS 缺时区时按记录规范与采集文件名核对并注明解释方式。主场头里的 DATE-OBS 可能继承第一张原始帧，不能把它当作 Master 生成时间。优先结合制作日志、FITS DATE 和既有处理记录；证据不够写“未记录”。不设统一过期天数。

复用Master时同时给出：原始库位置 → Master制作来源 → 当前process中的副本；若有校验哈希可附在明细中。复用时无需为了报告重算，但仍应解释主场当时的制作方法。

### 每一步的参数与结果

按实际执行顺序填写；没有运行的步骤不填成默认值：

1. 清点/转换：输入格式、FITS与预览配对、序列名、去马赛克状态、成功/失败数。
2. 主偏置/主暗场：实际原始张数、曝光、均值/中位叠加、输入归一化、剔除方法及参数、权重、输出归一化/位深、文件名、制作或复用状态。
3. 平场校准/主平场：使用了偏置、合成电平还是暗平场；平场张数和曝光；归一化、剔除、CFA处理、主平场路径和检查结果。
4. 亮场校准：实际Master路径与偏置扣除路线、暗场优化、坏点修正阈值/数量、CFA和解拜耳、试校准结果、整组成功/失败数。
5. 配准：参考帧、通道、方法/变换、两遍模式、星点检测设置、成功/失败数、FWHM/圆度/星数等用于判断的范围。
6. 筛片：排除编号与可追溯文件名、具体原因/指标；保留数量、累计亮场曝光。不要混淆一基帧号和零基API索引。
7. 应用配准/最终叠加：取景范围、插值/Drizzle设置、实际导出数；叠加算法、剔除阈值、输入归一化、权重、RGB均衡、输出归一化与位深、实际参与数、总曝光、拒绝率、输出路径。

字段以实际命令、日志和文件头为准；未写显式参数且无法核实默认值时标记“软件默认（未另行记录）”。wFWHM等加权叠加的累计曝光仍是保留原始帧曝光之和，不冒充某个精确等效SNR曝光。

### 预览与诊断

优先复用：主偏置/暗场/平场结构预览、代表亮场校准前后、坏帧与参考帧局部、最终线性叠加显示预览、低/高拒绝图。主场的强拉伸仅用于查看结构，不能按预览亮度直接比较其信号大小。灰尘平场的CFA合并预览应注明仅作诊断。

前后比较尽量相同显示变换、相同区域；独立拉伸用于看结构时明确标注。预览方向应与当前Siril/导出一致，必要时校验FITS行序。缺预览时可给可靠数值或日志结果，不能伪造截图。链接到可用的实际结果，报告内图像不依赖当前聊天或临时目录。

### 后期追加区

简明追加裁切尺寸、去梯度模型/参数、SPCC设备响应/恒星数/警告、降噪和去星模型/强度、采用与淘汰理由、线性/非线性状态、PS交接版本、交互合成最终参数与成片路径。用户尚在PS时写“等待返回”，预览标记为交PS前版本，不把旧预览当作最新编辑。

成片路径指向对应目标文件夹内实际采用的FITS/TIFF；同内容改名副本不算新处理版本。整理历史重复副本后同步更新报告与交付记录，避免指向已移除的外层文件。

## 交付前检查

核对原始/保留/排除数量和曝光计算；确认所述Master真被使用、原始库日期与制作日期分开；检查报告图片能加载、路径真实、数值和日志一致。未知与警告直接写明。报告应能回答用户“这张图用了什么、何时拍的校准场、怎么处理、每步得到什么”，而不是只罗列一堆文件名。

## 分享范围

报告默认保存在用户的目标目录。公开分享前确认范围，去除本机用户名、完整设备序列号、精确拍摄位置和不必要的个人路径；不能因为生成报告就自动上传原始素材或整个校准库。
